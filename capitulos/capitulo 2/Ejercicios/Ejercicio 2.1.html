Preguntas y respuestas

a) Una lista ordenada no puede anidarse dentro de una lista desordenada.

Falso Una lista ordenada puede anidarse dentro de una lista desordenada.

b) El elemento br representa un salto de línea.

Verdadero El elemento <br> inserta un salto de línea.

c) Los hipervínculos se denotan mediante el elemento link.

Falso Los hipervínculos se crean mediante el elemento <a> (ancla), utilizando el atributo href para indicar el destino del vínculo.

d) La anchura de todas las celdas de datos en una tabla debe ser igual.

Falso Las celdas de una tabla no tienen que tener necesariamente la misma anchura. Su tamaño puede variar dependiendo del contenido y del diseño de la tabla.

e) Estamos limitados a un máximo de cinco vínculos internos por página.

Falso HTML no establece un límite de cinco vínculos internos por página. Una página puede tener muchos vínculos internos.
