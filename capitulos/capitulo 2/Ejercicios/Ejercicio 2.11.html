Ejercicio 2.11

¿verdadero o falso?

a)Un documento de HTML5 válido no puede contener letras mayúsculas en nombres de elementos.
Respuesta: Falso. HTML5 permite utilizar letras mayúsculas en los nombres de los elementos.
b) Los documentos de HTML5 pueden tener la extensión de archivo .htm.
Respuesta: Verdadero. HTML5 admite tanto la extensión .html como .htm.
c)&less; es la referencia a entidad de carácter para el carácter menor que <.
Respuesta: Falso. la referencia correcta para representar el símbolo < es <
d)En un documento de HTML5 válido, li puede anidarse dentro de las etiquetas -ol- o -ul-.
Respuesta: Verdadero. Porque li representa un elemento de una lista y debe colocarse dentro de una lista ordenada -ol- o una lista desordenada -ul-.
