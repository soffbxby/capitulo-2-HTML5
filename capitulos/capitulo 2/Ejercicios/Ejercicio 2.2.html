Ejercicio 2.2

a) El elemento ______ inserta una regla horizontal.

El elemento <hr> inserta una regla horizontal.

b) Para marcar un superíndice se utiliza el elemento ______.

Para marcar un superíndice se utiliza el elemento <sup>.

c) El elemento de encabezado menos importante es ______.

El elemento de encabezado menos importante es <h6>.

d) El elemento ______ marca una lista desordenada.

El elemento <ul> marca una lista desordenada.

e) El elemento ______ marca un párrafo.

El elemento <p> marca un párrafo.

f) Para marcar un subíndice se utiliza el elemento ______.

Para marcar un subíndice se utiliza el elemento <sub>.

g) El elemento de encabezado más importante es ______.

El elemento de encabezado más importante es <h1>.

h) El atributo ______ en un elemento input inserta un botón que, cuando se presiona, restablece el contenido del formulario.

type="reset" en un elemento <input> inserta un botón que restablece el contenido del formulario.

i) El elemento ______ marca una fila de una tabla.

El elemento <tr> marca una fila de una tabla.

j) Los ______ se usan por lo general como caracteres de enmascarado en un cuadro de contraseña.

Los asteriscos (*) se usan por lo general como caracteres de enmascarado en un cuadro de contraseña.
